# Quick Reference Guide

## Admin — Managing the Form Library

CCHP Provider Form App | Cook Children's Health Plan

---

## Accessing the Admin Panel

1. Open the app to the **Form Library** (home screen).
2. Tap the **Admin** button in the top-right corner of the header (shield icon).
3. You will see the **Admin — Form Library** screen.

> The amber banner at the top confirms you are in the Admin panel.

---

## Understanding the Admin Panel

The Admin panel is divided into two sections:

- **Built-in Forms** — the two official CCHP forms pre-loaded in the app (Provider Visit 2026 and Site Evaluation Tool). These are **read-only** and cannot be edited or deleted.
- **Custom Forms** — any forms you have created. These can be edited or deleted.

---

## Creating a New Custom Form

1. Tap **Create New Form** at the bottom of the Admin screen.
2. Fill in the **Form Name** (required) — e.g., "Provider Credentialing Checklist".
3. Optionally add a **Description** — a brief note about what the form is for.
4. Add at least one **section** (a section groups related questions together).
5. Within each section, add **questions** as needed.
6. Tap **Save Form** when done.

The new form will immediately appear in the Form Library on the home screen.

---

## Building Sections & Questions

### Sections

Each form is divided into one or more sections. A section is a logical grouping of questions (e.g., "Provider Information", "Emergency Preparedness").

- **Add a section:** Tap the **+ Add Section** button.
- **Rename a section:** Click the section title and type directly in the title field.
- **Remove a section:** Tap the red trash icon on the section header.
- Sections can be collapsed/expanded by clicking the header row.

### Questions

Within each section, add one or more questions.

- **Add a question:** Tap **+ Add Question** inside the section.
- **Remove a question:** Tap the red trash icon on the question header.
- Questions can be collapsed/expanded by clicking the question header row.

### Question Fields

| Field | Required | Notes |
| --- | --- | --- |
| **Question label** | Yes | The text displayed to the user (e.g., "Provider Name") |
| **Question type** | Yes | See question type reference below |
| **Options** | Only for radio / checkbox | Add each option individually; press Enter or click Add |
| **Point value** | Yes/No/NA type only | Integer 0–10; points earned when user answers "Yes" |
| **Required** | No | Check to mark the field as required (shows red asterisk to user) |

---

## Question Type Reference

| Type | Use When… | User Experience |
| --- | --- | --- |
| **Text** | A short single-line answer is needed | Text input box |
| **Text (multi-line)** | A longer narrative answer is needed | Expandable textarea |
| **Date** | A specific date must be captured | Date picker |
| **Email** | An email address is needed | Email input (validated format) |
| **Phone number** | A phone number is needed | Phone input |
| **Single choice** | Only one answer from a list is allowed | Toggle buttons (only one stays selected) |
| **Multiple choice** | Any number of answers from a list are allowed | Checkbox buttons (multiple can be selected) |
| **Yes / No / NA (scored)** | A compliance or evaluation item needs a score | Table row with Yes/No/NA buttons and point value |

## Editing a Custom Form

1. In the Admin panel, find the custom form under **Custom Forms**.
2. Tap the **Edit** button on the form's card.
3. Modify the form name, description, sections, or questions as needed.
4. Tap **Save Form** to apply changes.

> Changes take effect immediately in the Form Library.

---

## Deleting a Custom Form

1. In the Admin panel, find the custom form under **Custom Forms**.
2. Tap the **trash icon** on the form card. A two-step confirmation appears.
3. Tap **Confirm** to permanently delete the form.
   - Tap **Cancel** to abort.

> **Warning:** Deleting a custom form also deletes any saved draft answers for that form. This action cannot be undone.

---

## Validation Rules

The app will show an error and prevent saving if:

- The **form name** is blank.
- There are **no sections** in the form.
- Any **question has an empty label**.

Fix the highlighted issue and tap **Save Form** again.

---

## Tips

- Built-in forms (Provider Visit 2026, Site Evaluation Tool) cannot be changed — they are locked to match the official CCHP paper documents.
- Custom forms use a general-purpose PDF layout. They will include the CCHP header and footer but will not replicate a specific paper form design.
- There is no limit to the number of custom forms you can add.
- Custom forms are stored in the browser on this device. If you need the same forms on another device, they must be recreated there.
